# 首页

## 当前主导航

主导航包含「今日」「闪卡」「我的」，切换时保留页面状态。
底栏使用 Flutter 绘制悬浮胶囊，支持拖动选中、按压形变和跟随拖动的表面高光，
松手后高光回到默认位置。减少动态效果开启时关闭高光位移和弹性形变。
拖动期间只预览胶囊位置，松手后切换到最近标签；系统取消触摸时保持原标签并恢复形状。
支持的渲染后端使用自定义 Shader 模拟边缘折射及轻微磨砂，否则回退到背景模糊。
这是接近 iOS 风格的实验性实现，尚未接入苹果原生 Liquid Glass，实际材质效果需真机验证。
首页主体当前使用渐变和示例任务卡片预览底栏效果，并未接入任务业务。

## 页面目标

首页帮助用户快速查看：

- 今天还有哪些任务没有完成
- 当前是否已经满足解锁条件
- 开始或完成任务

## 页面主要区域

### 今日状态

展示：

- 今日任务数量
- 已完成数量
- 未完成数量
- 当前 App 锁定状态

### 今日任务

展示当天任务列表。

### 解锁状态

当存在未完成任务：

受限 App 已锁定

当所有任务完成：

今日任务已完成
受限 App 已解锁

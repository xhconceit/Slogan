# 卡片与复习

## 页面结构

“卡片”主页面展示知识库、今日待复习数量和最近学习记录。

知识库详情展示卡片列表，并提供搜索、标签筛选、新建卡片和开始复习入口。

## 知识库管理

知识库列表支持创建、编辑和删除知识库。编辑时可以修改名称和可选描述，
并保留原有知识库 ID 和创建时间。删除前必须二次确认；确认后同时删除该知识库及其全部卡片。
操作失败时保留当前数据并提示用户重试。

## 创建卡片

用户先选择卡片类型，再填写该类型需要的内容。

所有类型包含：

- 所属知识库
- 题面
- 参考答案
- 解析
- 标签
- 来源

选择题增加选项和正确答案；语音卡增加语言、目标文本和通过条件；听力卡增加音频来源和回答方式。

## 复习流程

问答卡：

题面 → 主动回忆 → 翻面 → 查看答案 → 自评

选择题：

题面 → 选择答案 → 提交 → 正误反馈与解析 → 下一张

录音回答：

题面 → 开始录音 → 停止 → 回放或识别 → 判定 → 下一张

单词跟读：

查看单词 → 播放标准读音 → 跟读 → 识别目标文本 → 通过或重试

听力卡：

播放音频 → 输入、选择或录音回答 → 判定 → 查看原文和解析

## 异常与权限

- 首次使用录音时说明用途并申请麦克风权限。
- 权限被拒绝时保留卡片内容，并提供进入系统设置的入口。
- 录音中断、没有声音或识别失败时允许重试，不计为通过。
- 默认只保留最近一次练习录音；长期保存需要用户主动选择。

## 学习任务

用户可以把知识库复习设置为今日任务，并选择目标数量、卡片类型及通过条件。复习页面持续展示本次进度；满足目标后，Task System 将对应任务标记为完成。

# Task System

## 1. 职责

Task System 负责管理用户的任务以及任务完成状态。

主要职责：

- 创建任务
- 编辑任务
- 删除任务
- 生成今日任务
- 管理任务状态
- 判断单个任务是否完成

## 2. 任务类型

V1.0 支持两种任务类型。

### 2.1 专注计时任务

通过累计专注时间判断任务是否完成。

例如：

数学学习

目标：60 分钟

当累计有效专注时间达到 60 分钟后：

Task Status → Completed


### 2.2 手动完成任务

由用户主动确认任务完成。

例如：

整理房间

用户点击：

完成任务

↓

Task Status → Completed

V1.0 不验证手动完成任务的真实性。


## 3. 任务状态

任务包含以下核心状态：

Pending
↓
In Progress
↓
Completed


## 4. 状态转换

### 专注计时任务

Pending
↓
开始专注
↓
In Progress
↓
达到目标时间
↓
Completed

### Pending

任务已经创建，但尚未开始。

### In Progress

任务正在执行。

主要用于专注计时任务。

### Completed

任务已经满足完成条件。


### 手动完成任务

Pending
↓
用户点击完成
↓
Completed

## 5. 核心规则

### 5.1 任务创建

用户可以创建当天需要完成的任务。

任务创建后默认为未完成状态。


### 5.2 任务完成

不同任务类型使用各自的完成条件。

专注计时任务：

累计有效专注时间达到目标时间后自动完成。

手动完成任务：

用户主动确认后完成。


### 5.3 任务编辑

用户可以编辑未完成任务。


### 5.4 任务删除

用户可以删除任务。


## 6. 与其他系统的关系

Task System 不直接控制受限 App。

当以下事件发生时：

- 创建任务
- 删除任务
- 任务完成
- 任务状态发生变化

Task System 提供最新的今日任务状态。

Unlock Rule System 根据最新任务状态重新计算当前解锁状态。

流程：

Task System
↓
今日任务状态
↓
Unlock Rule System
